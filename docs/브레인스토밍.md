## Ⅰ. 프로젝트 개요 및 배경

### 1. 프로젝트 정체성
* **이름:** StoryFrame Studio Next (구 NeoMuse / StoryFrame Project)
* **슬로건:** *“시간이 오래 걸려도 실수 없이 완벽하게 — 창작자는 오직 감독(Director) 역할만 수행하는 스튜디오”*
* **정의:** AI 비디오 생성 모델(Grok, Midjourney, Kling, Runway, Wan 등)과 AI 음악(Suno 등)을 활용해 뮤직비디오, 단편 영상, 다큐멘터리 쇼츠를 제작할 때, **전체적인 서사와 타임라인의 큰 틀을 잡고 유동적으로 가편집까지 완성하는 로컬 데스크톱 워크스테이션**.

### 2. 왜 웹(SaaS)이 아닌 '단독 데스크톱 프로그램(.exe)'인가?
1. **서버 유지비 평생 0원:** 대용량 비디오/고화질 이미지를 AWS/클라우드 서버에 올리지 않고 사용자 로컬 SSD에서 직접 읽고 쓰므로 서버 비용 및 대역폭 비용이 전혀 발생하지 않음.
2. **프로그램 내 복잡한 API 연동 불필요:** 프로그램에 번거롭게 외부 AI API를 심을 필요가 없음. Antigravity가 터미널, 파일 제어, 추론까지 한 번에 다 해주는 **'API의 완전한 상위호환'**으로 상주하기 때문에, 프로그램은 순수하고 가벼운 전용 GUI 뷰어 역할에만 집중 가능.
3. **독립 소프트웨어 라이선스 판매 가능:** Gumroad, Lemon Squeezy 등을 통해 1회성 영구 라이선스로 판매 시 서버비 리스크 없이 판매 금액 전액이 순이익.
4. **로컬 파일 직접 제어의 압도적 속도:** Antigravity와 같은 로컬 컴퓨터에서 파일 시스템을 직접 공유하므로 반응 속도가 극대화됨.

## Ⅲ. 세션 기억 연속성 및 다중 프로젝트 체계

### 1. 토큰 다이어트 & 1초 세션 인수인계 (State Persistence)
* **문제:** 대화 세션을 하나로 길게 유지하면 토큰 소비가 극심해지고 AI가 앞 내용을 까먹음.
* **해결 구조:**
  * 대화창에 기억을 담지 않고, 로컬 프로젝트 폴더 내 `project_state.json`(진행 단계, 완성 컷, 잔여 작업)에 실시간 기록.
  * 대화가 길어지면 사용자는 언제든 **새 세션(New Chat)**을 생성.
  * 새 세션에서 *"프로젝트 이어서 하자"* 한마디만 하면, Antigravity가 `project_state.json`을 0.1초 만에 읽고 이전 상태를 100% 완벽 복원하여 작업 재개.

### 2. 다중 프로젝트 워크스페이스 (Multi-Project Hub)
* **목적:** 창작자가 여러 개의 뮤비(1번 뮤비, 2번 뮤비, 쇼츠 다큐 등)를 동시에 병렬 진행할 수 있도록 지원.
* **구조:**
  * **프로젝트 허브 홈 화면:** 진행 중인 작품들이 카드 형태로 나열 (제목, 장르, 진행률: 예: 18/24컷 완료, 최종 수정일).
  * **완전한 폴더 격리:**
    ```text
    projects/
    ├── 01_Night_Goes_On/        <-- 1번 뮤비 (Lo-Fi Jazz)
    ├── 02_UK_Drill_Fusion/      <-- 2번 뮤비
    └── 03_Dark_Tide/            <-- SF 단편 시네마틱
    ```
  * **원클릭 프로젝트 스위칭:** 프로그램에서 클릭 한 번으로 프로젝트를 전환하면 Antigravity도 즉시 해당 프로젝트 폴더로 작업 대상 변경.

## Ⅳ. 과거 '4단계 보드' 설계 계승 및 2026 최신화 업데이트

과거 확립했던 4대 보드 엔티티 모델(`Entity Model v3`)의 강력한 뼈대를 계승하되, 최신 AI 환경에 맞춰 비효율을 제거하고 진화시킴.

### 1단계: 스토리보드 (Story Board) — "음악과 거시적 서사"
* **기능:** 음악 타임라인과 가사에 맞춰 전체 씬과 컷의 거시적 호흡을 설계.
* **최신화 보강:**
  * **Gemini 오디오 멀티모달 분석:** 완성곡 MP3와 가사 텍스트를 입력하면, Gemini가 오디오 파형과 문맥을 분석해 각 소절의 **정확한 시작/종료 타임코드를 타임라인 마커로 자동 배치** (수동 타이핑 노가다 100% 제거).

### 2단계: 일러스트 보드 (Illustration Board) — "시각적 앵커 & 참조 이미지"
* **기능:** 영상화 전 정지 이미지(First Frame / F0) 재료 및 시각적 일관성 관리.
* **번호 체계 계승:** 기본 컷 `I22`, 동일 구도 디테일 변경 시 `I22-1`.
* **최신화 보강 (텍스트 탈피 ➔ 참조 이미지 중심):**
  * 텍스트 키워드 사전 중심에서 탈피하여, **[캐릭터 시트(정면/측면 레퍼런스 이미지)]** 및 **[공간/조명 무드보드 이미지]** 슬롯을 공식 탑재.
  * 최신 이미지/비디오 AI(Grok, Midjourney, Kling 등)에 최적화된 참조 이미지 기반 일관성 락(DNA Lock) 유지.

### 3단계: 영상화 보드 (Video Board) — "모션 생성 & 가챠 버전 관리"
* **기능:** 정지 일러스트(`I`)를 비디오 클립(`V`)으로 변환(I2V)하는 과정 통제.
* **번호 체계 계승:** `V22`, `V22-1`, `V22-1-2` (버전 관리).
* **최신화 보강:**
  * **가챠 멀티 슬롯 스택:** 컷 카드 하나 안에 `[Ver 1] [Ver 2] [Ver 3]` 탭을 두고, 타임라인 재생 중 단축키로 실시간 스위칭하며 어떤 버전이 전체 흐름에 맞는지 비교.
  * **AI 모션 난이도 신호등:** 컷 기획 시 AI가 감당 가능한 모션인지 자동 평가 (🟢 안전: 카메라 패닝/줌/바람 ➔ 🟡 주의: 걷기/고개돌리기 ➔ 🔴 위험: 복잡한 댄스/격투). 실패 확률이 높은 가챠 낭비 원천 차단.
  * **끝 프레임 원클릭 체이닝 (Chaining):** 앞 컷 비디오의 마지막 프레임을 버튼 하나로 추출하여 다음 컷의 시작 이미지(First Frame) 슬롯으로 즉시 연동.

### 4단계: 편집 보드 & 러프컷 오토 어셈블 (Editing & Rough Cut)
* **핵심 철학:** *"AI 클립 길이는 고정(5s/10s)하되, 최종 러닝타임은 편집 단계에서 Trim으로 수렴한다."*
* **최신화 보강 (러프컷 실시간 가편집 워크벤치):**
  * **단순 뷰어가 아닌 실시간 가편집 작업대:** 대형 플레이어에서 음악과 함께 전체 영상을 재생하면서, 마음에 안 드는 컷이 나오면 즉시:
    1. **미세 트리밍:** 인앤아웃(In/Out) 슬라이더로 앞 1초, 뒤 1.5초를 마우스로 잘라내기.
    2. **순서 스왑:** 드래그 앤 드롭으로 컷 순서 맞바꾸기.
    3. **버전 교체:** 원클릭으로 다른 가챠 버전으로 갈아 끼우기.
  * **비트 마그넷 스냅 (Beat Snap):** 음악의 킥/스네어 비트선에 마우스가 자석처럼 달라붙어, 대충 긁어도 컷 전환이 음악 박자와 칼같이 일치.
  * **FFmpeg 1초 무손실 조립:** 무거운 캡컷/프리미어 렌더링 없이, 잘라둔 구간들만 백그라운드 터미널에서 무손실로 1~2초 만에 즉시 결합해 재생.
  * **상용 툴 탈출구 (FCPXML / CapCut Export):** 정밀 자막, 색보정 등 최종 마무리가 필요할 때를 위해 원클릭으로 캡컷/프리미어 프로 타임라인 프로젝트로 내보내기 지원.

## Ⅶ. 하이엔드 UI/UX 디자인 시스템 & 비주얼 가이드라인 (최신 UI 리서치 반영)
> **출처 레퍼런스:** `C:\Users\YuBin2\Desktop\새 폴더 (2)\최신 ui` (Linear, Arc, Notion Calendar 분석서)

### 1. Linear 스타일: "다크-퍼스트(Dark-First) & 오프블랙" 색상 체계
* **베이스 캔버스:** 퓨어 블랙(`rgb(0,0,0)`)을 철저히 배제하고, 눈치채기 어려울 만큼 미세한 푸른빛이 도는 오프블랙(`rgb(1, 1, 2)` / `#010102`)을 배경으로 채택.
* **표면 계층(Surface Elevation):** OKLCH 색상 공간을 기반으로 레이어 깊이가 올라갈수록 표면 밝기를 수학적으로 미세하게 올려, 컴포넌트가 우주 공간에 부양된 듯한 입체적 깊이감 형성.
* **타이포그래피 밀도 제어:** Inter 폰트 자간을 극단적으로 압축(`-1.5px`)해 정보 자체의 밀도를 높이고, 주변 여백(Padding)을 넓게 주어 정보 덩어리와 암흑 공간 사이에 극적인 긴장감 연출.

### 2. Notion Calendar (구 Cron) 스타일: "정밀 픽셀 타임라인"
* **타임라인 컷 블록 디자인:**
  * 각 컷 블록의 **왼쪽 테두리에만 또렷한 2px 액센트 선(Border)**을 긋고,
  * 내부는 동일 색상의 채도를 대폭 낮춘 **반투명(Opacity)**으로 채움.
  * ➔ 컷들이 타임라인에 빽빽하게 이어붙거나 겹쳐도 시작점과 구간이 1픽셀 오차 없이 선명하게 식별됨.
* **지연 없는 반응성:** 복잡한 타임라인 드래그/트리밍 시 60FPS 이상의 프레임 드롭 없는 마이크로 인터랙션 보장.

### 3. Arc Browser 스타일: "접이식 세로 사이드바 & Peek(오버레이)"
* **화면 낭비 제거:** 상단 수평 탭을 없애고, 좌측에 숨기거나 꺼낼 수 있는 **반투명 세로형 사이드바**를 두어 영상 모니터 캔버스 공간을 극대화.
* **Peek(플로팅 패널) 플로우:** 컷 카드를 클릭했을 때 화면이 새로고침되거나 전환되지 않고, 카드 위에 자연스럽게 떠오르는 플로팅 패널로 세부 연출 정보를 확인/수정.

### 4. 벤토 그리드(Bento Grid) 카드 아키텍처
* 컷 카드 내부에 [대본], [카메라 앵글], [모션 난이도], [비디오 프리뷰], [가챠 슬롯]을 잡다한 텍스트 나열이 아니라, 애플 스타일의 규격화된 네모 박스(Bento Box)로 모듈화하여 배치.

### 5. 프론트엔드 엔지니어링 표준 스택
* **UI 컴포넌트:** `shadcn/ui` (컴포넌트 소유권 100%, Radix UI 기반)
* **스타일링:** `Tailwind CSS` (OKLCH 컬러 공간)
* **아이콘:** `Lucide Icons` (선 두께 1.5px 미니멀리즘 데스크톱 룩)
* **모션 엔진:** `Framer Motion` (스프링 물리 텐션 애니메이션 적용)
